# 내 PC를 서버로 쓰기 (Windows)

항상 켜져 있는 Windows PC에서 봇을 돌리는 방법입니다. 설치는 **ZIP 다운로드 → `install.bat` 더블클릭 → 휴대폰에서 [시작]** 순서로 끝납니다.

필요한 것: **Python 3.10 이상**, 텔레그램 봇 토큰

---

## 1. 텔레그램 봇 만들기 (처음 한 번)

1. 텔레그램에서 **@BotFather** 를 검색해 대화를 시작합니다.
2. `/newbot` 을 보냅니다.
3. 봇 이름을 입력합니다 (예: `내 포트폴리오`).
4. 봇 아이디를 입력합니다. 아이디는 **`bot` 으로 끝나야 합니다** (예: `my_pf_alert_bot`).
5. 받은 **토큰**(`123456789:AA...`)을 복사해 둡니다. 비밀번호처럼 다루세요.

## 2. 설치

1. <https://github.com/gamhu0919-sudo/TradingView-for-me> 에서 초록색 **Code** 버튼 → **Download ZIP** 을 누릅니다.
2. 받은 ZIP을 **오른쪽 클릭 → 압축 풀기** 합니다. 바탕화면이나 다운로드 폴더 등 아무 곳에 풀어도 됩니다.
3. 압축을 푼 폴더에서 **`install.bat`** 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
4. 파란 창에서 설치가 진행됩니다. 처음에는 1~2분 걸립니다.
   - **토큰을 물어보면** 1단계의 토큰을 붙여넣고 Enter를 누릅니다. 붙여넣기는 Ctrl+V 또는 마우스 오른쪽 클릭입니다.
5. 창에 **`https://t.me/봇아이디`** 링크가 나옵니다. **휴대폰 텔레그램에서 그 링크를 열고**, 봇 대화방 아래의 **[시작]** 버튼을 누릅니다.
6. 창에 **"완료! 등록되었습니다"** 가 나오고 텔레그램으로 환영 메시지가 오면 설치가 끝난 것입니다. 🎉

`install.bat` 이 자동으로 해주는 일:
- 파일을 `C:\portfolio-bot` 에 설치합니다. 설치가 끝나면 압축을 푼 폴더는 지워도 됩니다.
- 필요한 패키지를 설치하고, 토큰이 맞는지와 텔레그램에 연결되는지 확인합니다.
- Windows에 로그인할 때 자동으로 시작되도록 등록하고, 창 없이 백그라운드에서 실행합니다.
- 휴대폰에서 [시작]을 누른 대화를 **봇 주인으로 자동 등록**합니다. 그 뒤로 봇은 이 대화에만 응답합니다.

## 3. PC 절전 끄기 (중요)

- **설정 → 시스템 → 전원(및 배터리) → 화면 및 절전** 에서 **"절전 모드로 전환"** 을 **"안 함"** 으로 바꿉니다. 화면 끄기 설정은 그대로 둬도 됩니다.
- **노트북이라면** 제어판 → 전원 옵션 → **"덮개를 닫으면"** 을 **"아무 것도 안 함"** 으로 바꾸고, 전원 어댑터를 연결해 두세요.

## 4. 보유 종목 입력

텔레그램에서 봇에게 아래처럼 보냅니다.

```
/add 삼성전자 30 180000
/add 애플 10 300 @1380
/add 비트코인 0.05 95000000
/cash 2000000
/now
```

- 형식은 `/add 종목 수량 평단가` 입니다. 미국 주식 뒤의 `@1380` 은 매수 당시 환율이며, 넣지 않아도 됩니다.
- 알림 시각은 `/schedule` 로, 전체 명령어는 `/help` 로 확인합니다.

## 사용하면서

| 하고 싶은 일 | 방법 |
|---|---|
| **업데이트** | 새 ZIP을 받아 압축을 풀고, 그 안의 **`install.bat`** 을 실행합니다. 토큰과 보유 종목은 그대로 유지됩니다 |
| 봇 재시작 | `C:\portfolio-bot\install.bat` 실행 |
| 봇 중지 | `C:\portfolio-bot\scripts\windows\stop_bot.bat` |
| 로그 보기 | `C:\portfolio-bot\scripts\windows\open_log.bat` |
| 자동 시작 해제 | `C:\portfolio-bot\scripts\windows\uninstall_autostart.bat` |

- **봇이 동작하는 조건**
  - PC가 켜져 있고 Windows에 **로그인된 상태**여야 합니다. 화면 잠금 상태는 괜찮습니다.
  - 재부팅했다면 로그인하는 순간 자동으로 다시 시작됩니다.
- **클라우드와 PC에서 같은 봇을 동시에 실행하지 마세요.** 텔레그램은 봇 하나당 연결을 하나만 허용합니다.
- **데이터와 백업**
  - 보유 종목과 일정은 `C:\portfolio-bot\data\portfolio.db` 에 저장됩니다.
  - 매일 07:10에 `data\backups\` 로 자동 백업됩니다.
  - PC 고장에 대비해 가끔 `/export` 로 CSV를 받아 두세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "Python 을 찾지 못했습니다" | 아래 **PATH 설정** 을 따라 합니다 |
| "토큰이 올바르지 않습니다" | BotFather 메시지의 토큰을 다시 복사합니다. `숫자:문자` 전체를 앞뒤 공백 없이 붙여넣었는지 확인하세요 |
| "텔레그램 서버에 연결하지 못했습니다" | 회사·학교 네트워크나 백신 프로그램이 텔레그램을 막고 있을 수 있습니다. PC를 휴대폰 핫스팟에 연결하고 `install.bat` 을 다시 실행해 결과를 비교해 보세요 |
| 휴대폰 검색에 봇이 안 나옴 | 새로 만든 봇은 검색에 늦게 나옵니다. `https://t.me/봇아이디` 링크로 여세요. 아이디를 모르면 BotFather에게 `/mybots` 를 보냅니다 |
| 정기 알림이 안 옴 | PC 절전 설정을 확인하고, `open_log.bat` 로 로그에 오류가 있는지 봅니다 |
| 로그에 `Conflict` 오류 | 다른 곳(클라우드 서버 등)에서 같은 봇이 실행 중인지 확인합니다 |

### PATH 설정

PATH는 Windows가 `python` 같은 명령을 찾을 때 살펴보는 폴더 목록입니다. Python 폴더가 이 목록에 없으면, Python이 설치돼 있어도 찾지 못합니다.

1. **Windows 키** → `cmd` 입력 → 명령 프롬프트에서 `py --version` 을 입력합니다. `Python 3.10.x` 처럼 버전이 나오면 PATH는 문제없습니다.
2. 버전이 나오지 않으면: **설정 → 앱 → 설치된 앱** → **Python 3.10.x** → **수정** → **Modify** → **Next** 로 들어가 **"Add Python to environment variables"** 를 체크하고 **Install** 을 누릅니다.
3. 그다음 `install.bat` 을 다시 실행합니다.

## Mac이라면

터미널에서 아래를 실행합니다. 로그인할 때 자동으로 시작되게 하려면 별도 설정이 필요하니 요청해 주세요.

```bash
git clone https://github.com/gamhu0919-sudo/TradingView-for-me.git ~/portfolio-bot && cd ~/portfolio-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && open -e .env     # 토큰 입력 후 저장
LOG_FILE=data/bot.log nohup .venv/bin/python -m bot >/dev/null 2>&1 &
```

그다음 휴대폰에서 봇에게 [시작]을 누르면 자동으로 등록됩니다.
