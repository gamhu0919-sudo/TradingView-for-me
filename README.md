# TradingView-for-me · 포트폴리오 텔레그램 알림 봇

보유 중인 **국내 주식·미국 주식·코인**과 **주요 지수·환율**을 정해진 시각에 한 번에 정리해 텔레그램으로 보내주는 봇입니다.

- 🔑 **증권사·거래소 개인 API 키를 쓰지 않습니다.** 공개 시세만 조회하므로 계좌와 연결된 정보가 없습니다.
- 🕗 **넥스트레이드(NXT) 프리·애프터마켓**과 **미국 프리·애프터마켓** 가격까지 반영합니다.
- ✍️ 보유 종목은 텔레그램에서 직접 입력합니다 (`/add 삼성전자 10 58000`).
- ⏰ 알림 시각을 자유롭게 설정합니다. `국장마감+10m`처럼 시장 시간 기준으로도 설정할 수 있고, 서머타임과 휴장일은 자동으로 반영됩니다.

## 명령어

| 명령어 | 설명 |
|---|---|
| `/now [전체\|간단\|코인\|주간]` | 지금 바로 리포트 받기 |
| `/pf` | 보유 종목 상세 (각 종목의 `#번호` 표시) |
| `/add 삼성전자 10 58000` | 매수 기록. 이미 보유한 종목이면 평단가를 가중평균으로 다시 계산 |
| `/add AAPL 5 185.5 @1380` | 미국 주식 매수. `@매수환율`을 넣으면 환차손익을 따로 보여줌 |
| `/add BTC 0.01 95000000` | 코인 매수 (원화 가격) |
| `/sell 삼성전자 5 70000` | 매도 기록과 실현손익 계산. 수량 대신 `전량`도 가능 |
| `/set 삼성전자 50 58000` | 수량·평단가를 직접 덮어쓰기 (처음 입력할 때 편리) |
| `/del 3` | `#3` 종목 삭제 |
| `/cash 3000000`, `/cash USD 500` | 현금(예수금) 설정. `0`을 넣으면 삭제 |
| `/history` | 최근 거래 기록 |
| `/export` | CSV 파일로 백업. 그 파일을 봇에게 다시 보내면 일괄 입력 |
| `/schedule` | 알림 일정 목록 (버튼으로 끄기·삭제) |
| `/schedule add <일정>` | 알림 일정 추가 (아래 문법 참고) |
| `/alert 삼성전자 250000` | 목표가 알림. 현재가보다 높으면 '이상', 낮으면 '이하'로 자동 설정 |
| `/threshold 5` | 하루 ±5% 급등락 알림 (`off`로 끄기). ±10%, ±15%처럼 단계가 올라가면 다시 알림 |

종목명이 여러 종목과 겹치면(예: `BTC`는 미국 ETF와 코인 두 가지) 버튼으로 어떤 종목인지 묻습니다.

### 알림 일정 문법

| 예시 | 의미 |
|---|---|
| `08:30` | 평일 08:30 전체 브리핑 |
| `08:30 매일 코인` | 매일 08:30 코인 요약 |
| `월수금 07:00 간단` | 월·수·금 07:00 간단 요약 |
| `09:05 개장일 간단` | 국내 개장일(휴장일 제외) 09:05 |
| `국장마감+10m` | 국내 개장일마다 15:40 |
| `NXT마감+5분 간단` | 넥스트레이드 애프터마켓 마감(20:00) 5분 뒤 |
| `미장개장+15m 간단` | 미국 개장 15분 뒤 (서머타임이면 22:45, 아니면 23:45) |
| `미장마감+10m` | 미국 장 마감 10분 뒤 (한국 시각으로 다음 날 새벽) |
| `매시 09-15 간단` | 평일 09:00~15:00 매 정각 |
| `매30분 09:00-15:30 간단` | 평일 30분 간격 |
| `일 20:00 주간` | 일요일 20:00 주간 리포트 |

- **기준점:** `국장프리`(08:00), `국장개장`(09:00), `국장마감`(15:30), `NXT마감`(20:00), `미장프리`(04:00 ET), `미장개장`(09:30 ET), `미장마감`(16:00 ET)
- **요일:** `매일`, `평일`, `주말`, `월수금`처럼 요일 글자 조합, `개장일`
- **종류:** `전체`, `간단`, `코인`, `주간`

봇을 처음 실행하면 기본 일정 4개(`08:30 평일 전체`, `국장마감+10m 전체`, `미장개장+10m 간단`, `일 20:00 주간`)가 등록됩니다. 필요 없는 일정은 `/schedule`에서 지우면 됩니다.

### 자동으로 하는 일

- **급등락·목표가 확인:** 5분마다 합니다. 국내 주식은 08:00~20:00(넥스트레이드 포함), 미국 주식은 현지 04:00~20:00, 코인은 24시간 확인합니다.
- **무음 시간대:** 00:00~07:00에 울리는 알림은 무음으로 보냅니다(`ALERT_QUIET_HOURS`로 변경 가능).
- **자산 기록:** 매일 07:10에 총자산을 기록하고, 이 값으로 주간 리포트의 '지난주 대비'를 계산합니다. 데이터베이스 백업도 같이 만들며, 요일별로 7개를 순환 보관합니다.

## 시세 소스

| 대상 | 소스 | 비고 |
|---|---|---|
| 국내 주식·ETF·지수 | 네이버 증권 | 실시간. 넥스트레이드 프리·애프터 포함 |
| 미국 주식·지수 | 네이버 증권 | 실시간. 프리·애프터 포함 |
| 원/달러 | 네이버 (하나은행 고시) | |
| 코인 | 업비트 공개 API | 실시간. 등락률은 매일 09:00 기준 |
| 코인 공포탐욕지수 | alternative.me | 하루 1회 갱신 |
| 예비 소스 | Yahoo Finance | 네이버 조회 실패 시 자동 전환 (지연 시세일 수 있음) |

> 네이버 증권 시세는 공식 API가 아니어서 예고 없이 형식이 바뀔 수 있습니다. 이 봇은 개인 알림 용도로 몇 분 간격으로만 조회합니다. 조회가 실패하면 Yahoo로 대신 조회하고, 메시지의 '특이사항'에 그 사실을 표시합니다.

## 설치

클라우드 서버에 설치하는 방법은 **[docs/DEPLOY.md](docs/DEPLOY.md)** 에 단계별로 정리돼 있습니다 (Google Cloud 무료 서버 기준, Oracle Cloud 대안 포함).

로컬에서 빠르게 확인하려면:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m bot preview 전체 --sample   # 텔레그램 없이 예시 포트폴리오로 리포트 출력
pytest                                # 테스트
cp .env.example .env                  # 토큰 입력 후
python -m bot                         # 봇 실행
```

## 보안

- 이 저장소는 **공개 저장소**입니다. 봇 토큰(`.env`)과 보유 내역(`data/`)은 서버에만 저장되며 `.gitignore`로 커밋을 막아 두었습니다.
- 봇은 `.env`에 등록한 본인 `TELEGRAM_CHAT_ID`의 명령에만 응답합니다.
- 봇이 외부에 여는 포트는 없습니다. 텔레그램 서버에 먼저 접속해 메시지를 가져오는 방식(롱폴링)입니다.
- 봇 토큰이 유출됐다면 BotFather에서 `/revoke`로 새 토큰을 받으세요.

## 구조

```
bot/
  sources/        시세 어댑터 (naver, upbit, yahoo, sentiment)
  market_data.py  여러 소스를 묶어 조회하고 실패 시 Yahoo로 대체
  market.py       장 운영시간·휴장일 (서머타임 자동 반영)
  schedules.py    알림 일정 문법 해석과 실행 시각 판정
  storage.py      SQLite (보유 종목·거래 기록·현금·일정·목표가·스냅샷)
  portfolio.py    평가금액·손익·환차손익 계산
  report.py       텔레그램 메시지 생성
  service.py      리포트·급등락·목표가 알림 로직
  telegram_bot.py 명령어 처리와 정기 작업
```
